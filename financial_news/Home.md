## What this vault is for
This vault turns the `d-ai-trader` news capture pipeline into a searchable Obsidian knowledge base.

Each daily note can contain:
- screenshots from source sites
- extracted headlines
- trading-relevant insights
- source tags for fast filtering/search

## Suggested workflow
1. Open the latest daily note.
2. Review screenshots and extracted insights.
3. Pull recurring narratives into [[Themes/Home|Themes]].
4. Use weekly notes to consolidate the real signal and ignore the noise.

## Current structure
- `YYYY-MM/` → daily imported notes
- `attachments/YYYY-MM-DD/` → screenshots copied alongside notes
- `Sources/` → source-specific landing notes
- `Themes/` → weekly or narrative clustering notes
- `Templates/` → starter note templates for manual curation

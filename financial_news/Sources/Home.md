# Source Profiles

This folder holds manually maintained source notes.
Generated imports now link directly to source profiles when the agent name is recognized, so this page is a reference map rather than a required graph hub.

## Fast-tape / intraday sources

- [[CNBC]] → market movers, relative strength, intraday tape color
- [[Benzinga]] → momentum headlines when the automation is healthy
- [[Yahoo Finance]] → broad baseline market framing

## Company / consumer / crossover sources

- [[Fox Business]] → company-specific catalysts, retail, consumer, macro crossover
- [[AP Business]] → slower, cleaner business-policy framing

## Macro / international context

- [[BBC Business]] → global business and policy context when the feed is healthy
